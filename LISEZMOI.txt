DEMARRAGE RAPIDE (5 MINUTES)
===============================================================

ETAPE 1 : COPIER VOS FICHIERS
---------------------------------------------------------------
Copiez tous vos fichiers depuis Lumi dans ce dossier :
   
   - src/components/  -> Vos composants
   - src/screens/     -> Vos ecrans
   - src/hooks/       -> Vos hooks
   - src/services/    -> Vos services
   
ATTENTION : NE PAS ecraser les fichiers deja presents !


ETAPE 2 : CREER PROJET SUPABASE
---------------------------------------------------------------
-> Aller sur https://supabase.com
-> Se connecter / Creer un compte
-> New Project
   • Nom : depannage-entretien
   • Password : (choisir un mot de passe fort)
   • Region : Europe (Paris)
-> Attendre 2-3 minutes


ETAPE 3 : CONFIGURER LA BASE DE DONNEES
---------------------------------------------------------------
Dans Supabase :
   
-> SQL Editor
-> New Query
-> Copier le contenu de :
   supabase/migrations/20260207_initial_schema.sql
-> Run
-> Verifier qu'il n'y a pas d'erreurs


ETAPE 4 : RECUPERER LES CLES
---------------------------------------------------------------
Dans Supabase :
   
-> Settings -> API
-> Copier :
   • Project URL
   • anon public key


ETAPE 5 : CONFIGURER L'APPLICATION
---------------------------------------------------------------
Dans votre terminal :
   
$ cd depannage-entretien
$ cp .env.example .env
$ nano .env    (ou ouvrir avec un editeur)
   
Remplir :
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJxxx...


ETAPE 6 : INSTALLER ET MIGRER
---------------------------------------------------------------
$ npm install
$ ./migrate-to-supabase.sh
   
Le script va :
[OK] Faire un backup de votre code
[OK] Remplacer les imports Lumi -> Supabase
[OK] Verifier la configuration


ETAPE 7 : LANCER L'APPLICATION
---------------------------------------------------------------
$ npm run dev
   
-> Ouvrir http://localhost:3000
-> Se connecter avec contact@appalacarte.fr
